# translateApp

Android app for translating `strings.xml` resource files.

#### How to use
1. Open the app
2. Select the XML file you want to translate
3. Wait for the file analysis to finish
4. Copy the text **exactly as it is** into Google Translate (or any other translator)
5. Paste the translated output back into the app
6. Click **Save translation**, choose where to save, and wait for saving to finish
7. Done – you now have a translated resource file
